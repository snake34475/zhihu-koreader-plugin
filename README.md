# Zhihu KOReader Plugin

面向 Kindle + KOReader 的知乎只读客户端原型。**项目于 2026-11-02 暂时搁置，保存代码与设计供后续继续；当前版本不是完整知乎阅读器。**

## 目标

最终期望：在 Kindle 上刷推荐列表、看热榜，点击后阅读回答全文，并浏览评论与回复。推荐列表接受按收藏、关注主题生成，不强求复刻知乎登录后的个性化首页。

允许探索预抓取、收藏夹同步及自有后端，前提是先验证实际能取得全文与评论，不能把摘要当作全文。完整需求和待验证方案见 [IDEAS.md](IDEAS.md)。

当前 `0.2.0` 仍是 Kindle 直连官方接口的原型，实现：

- 知乎热榜
- 知乎站内搜索
- 全网搜索（可选）
- 知乎直答
- 结果缓存与离线重读

当前尚未实现推荐列表、通用他人回答全文、完整评论、收藏夹同步、预抓取、后端或登录会话管理。点赞、评论发布、关注操作、私信和视频播放不在只读目标中。

## 目标设备

- Kindle Paperwhite 4（用户设备）
- KOReader 2026.07.x
- Lua KOReader plugin API

## 重要安全边界

- 当前代码只使用知乎开放平台 API，不使用反编译的移动端私有接口；未来内容获取方案需单独验证，尚未实施。
- Access Secret 不得提交到 Git、日志、截图或命令行。
- 不在后台轮询；所有请求由用户主动触发。
- 配置文件和缓存需要在设备上单独备份，仓库只保存示例配置。

## 当前状态

已实现 `0.2.0`：热榜内容首页、问题回答摘要列表、上一批/下一批、回答阅读导航，以及配置、搜索、直答、取消/超时和离线缓存。

53 项离线测试已在 LuaJIT 2.1 通过，并已在 PW4 的真实 KOReader 控件与 JSON 库上生成和检查首页、回答列表、阅读页预览。真实鉴权、触屏操作和持续使用仍待验收，不能视为 MVP 验收完成。

插件说明与安装步骤见 [zhihu.koplugin/README.md](zhihu.koplugin/README.md)。已建立 SSH 安装流程，更新会备份旧插件并保留设备配置；测试只使用虚构内容，不读取或展示用户密钥。

当前已知缺口：官方问题回答接口提供摘要；搜索可能附带精选评论；官方创作全文和创作评论接口限制为账号本人的内容。切换 CLI/MCP 本身不解决通用全文、评论缺口。

详细设计见 [PLAN.md](PLAN.md)，完成情况与恢复顺序见 [TODO.md](TODO.md)，全部扩展想法见 [IDEAS.md](IDEAS.md)。新对话先阅读这些文档及 [NEXT_PROMPT.md](NEXT_PROMPT.md)。

## 凭证与隐私

仓库只包含空密钥示例与虚构测试数据，不包含设备真实配置、Access Secret、Cookie、SSH 私钥、缓存、部署包或设备截图。运行配置保存到设备 KOReader 数据目录的 `settings/zhihu_configuration.json`，不要提交该文件。

Git 忽略规则是辅助措施，提交前仍需检查暂存文件。手机扫码填写密钥只是设计方案，当前没有此功能；可通过设备设置页填写，或自行使用加密 SSH/SCP 编辑配置。

## 本地测试

开发机需要 Python 和 `lupa`，设备端无需安装它们。在项目根目录运行：

```powershell
python -m pip install lupa
python zhihu.koplugin/tests/run.py
```

测试只使用自行编写的虚构 JSON fixture，不发送网络请求，不读取真实配置。覆盖范围和运行方式见插件说明。
