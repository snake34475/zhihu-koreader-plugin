# 知乎 KUAL 独立版

本目录用于开发由 KUAL 启动的独立 Kindle 阅读程序。当前阶段只有产品与 UI 需求，尚无 KUAL 可执行程序或可用的独立版界面。

- [UI 产品需求](PRODUCT_REQUIREMENTS.md)：现有 KOReader 原型的功能基线、KUAL 独立版页面、墨水屏约束、亮度/暗黑模式/刷新设置及设计交付要求。
- 设计评审先使用 Mac 上的交互原型；真实字体、触摸、前光、暗黑模式、屏幕刷新和启动耗时以 PW4 实机验收。
- KUAL 只负责启动；独立版需要自己的界面、设备适配和会话管理。现有 `zhihu.koplugin` 继续在 `main` 分支维护，不能直接当作 KUAL 程序运行。

后续实现应先完成最小的首页、回答页和评论页原型，并分别验证 Mac 预览与 Kindle 上的显示、触摸和刷新，再接入现有知乎内容流程。
