# 知乎扫码实验插件

这是独立于 `zhihu.koplugin` 的可行性实验。将整个 `zhihu-qr-probe.koplugin` 目录放入 KOReader 的 `plugins/`，重启后打开「工具 → 知乎扫码实验」。实验只请求知乎登录页、设备初始化、二维码和扫码状态接口；不保存 Cookie，也不请求回答正文。

电脑上使用普通 HTTPS 曾验证：登录页、`/udid` 和二维码接口可返回 200；扫码状态请求返回 40352（环境验证）。随后在 PW4 上，登录页直接重定向到知乎的人机验证页；继续对比时，电脑上的普通 HTTP 和完整浏览器也都被重定向到同类页面。因此不能把差异归因于 Kindle 缺少某个请求头。插件会明确显示这些状态并停止，不会声称登录成功。手机扫码只应在自己确认的知乎官方页面进行。

实验流程及现有插件严格隔离，开放平台 Access Secret 不会发送到 `www.zhihu.com`。如要移除实验，删除本插件目录并重启 KOReader。
