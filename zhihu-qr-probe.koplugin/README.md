# 知乎扫码实验插件

这是独立于 `zhihu.koplugin` 的可行性实验。将整个 `zhihu-qr-probe.koplugin` 目录放入 KOReader 的 `plugins/`，重启后打开「工具 → 知乎扫码实验」。实验分别报告登录页、二维码、扫码确认和 `/api/v4/me` 会话校验；Cookie 只留在当前进程内存，不写入磁盘，也不请求回答正文。

2026-11-03 在 PW4 上运行新版设备探针，登录页返回 HTTP 302 并识别为 `verification_required`；探针在 `/signin` 阶段停止，未请求 `/udid`、未生成二维码。此前的电脑与设备结果仍是各自时间点的观察。按计划不通过浏览器伪装、改请求头或自动解题继续登录路线。若登录页可以通过，后续代码会分别处理二维码过期、会话失效和 `/api/v4/me` 校验；扫码确认本身不作为登录成功。

实验流程及现有插件严格隔离，开放平台 Access Secret 不会发送到 `www.zhihu.com`。如要移除实验，删除本插件目录并重启 KOReader。
